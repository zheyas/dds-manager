# DDS Менеджер

DDS Менеджер — это веб-приложение для учёта доходов и расходов с авторизацией пользователей. Вы можете создавать категории, добавлять доходы и расходы, отслеживать финансовые операции, просматривать отчёты и сохранять данные по пользователю.

## 🚀 Возможности

- Регистрация и вход пользователей
- Учёт доходов и расходов, в том числе учёт кешбэка
- Разделение на категории и подкатегории
- Просмотр последних 5 операций на главной странице
- Выборка операция по свойствам за промежуток времени
- Разделение по типу: доходы, расходы
- Редактирование и удаление операций
- Интуитивно понятный интерфейс
- Получение текущего курса валют

## 🛠️ Установка

1. **Клонируйте репозиторий:**

```git clone https://github.com/zheyas/dds-manager.git```
```cd dds-manager```

2. **Создайте и активируйте виртуальное окружение:**
```
python -m venv .venv
```
source .venv/bin/activate  # или .venv\Scripts\activate на Windows

3. **Установите зависимости:**
```
pip install -r requirements.txt
```
4. **Примените миграции и создайте суперпользователя:**
```
python manage.py migrate
python manage.py createsuperuser
```
5. **Запустите локальный сервер:**
```
python manage.py runserver
```
6. **Перейдите в браузере:**

http://127.0.0.1:8000/
